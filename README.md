FloodSense: Intelligent Flood Relief Management System

//Overview
FloodSense is an intelligent flood-relief management system designed to support faster and more organized disaster response during floods in Assam, India.
Flood emergencies often generate urgent requests for food, clean water, shelter, medical assistance, and rescue services. However, identifying these needs, prioritizing requests, checking resource availability, and coordinating relief distribution can be time-consuming when handled manually.
